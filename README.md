# Spaceship Titanic

Соревнование на Kaggle [Spaceship Titanic](https://www.kaggle.com/competitions/spaceship-titanic).

## Что делал:
  1) Изучил распределения признаков, построил boxplot'ы для числовых признаков в зависимости от таргета.
  2) В данных оказалось много пропусков, сперва решил их просто удалять.
  3) Признак Сabin можно разбить на номер каюты, палубу и часть корабля, потом закодировать.
  4) Признак PassengerId разбивается на номер группы и номер человека в группе, из этих данных сохраняем размер группы человека, остальное удаляем.
  5) Признак Name разумно обработать не получается, просто удаляем.
  6) После этого запустил поиск по сетке с кросс-валидацией для catboost. Лучшая модель на тесте показала accuracy 0.79705.
  7) Пропусков в данных все-таки слишком много, чтобы их удалять. Попробуем осмысленно заполнить.
  8) Существует разумное предположение, что человек, пользующийся криосном не тратит деньги на допуслуги и наоборот. Boxplot'ы подтверждают эту гипотезу. Тогда человеку с нулевыми тратами и пропуском в колонке криосна ставим True, остальным False. Человеку с True в столбце криосна ставим нулевые траты.
  9) Остальные числовые признаки заполняем медианой.
  10) У некоторых людей есть пропуск в столбце Cabin. Мы можем предположить, что люди из одной группы путешествуют в одной каюте. Тогда по номеру группы можно подставить человеку пропущенную каюту.
  11) Незаполненными остаются только планеты отправления и прибытия. Посмотрим на корреляции между этими признаками (они имеют всего по 3 значения).
  12) Несколько значений имеют корреляцию больше 0.5, заполняем эти пропуски соответствующими значениями, остальное модой. Таким образом, все пропуски заполнены.
  13) Вновь пробуем тот же gridsearchCV для catboost, accuracy на тесте - 0.79822. Теперь надо перебирать модели.
