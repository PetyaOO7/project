# Rain in Australia - EDA и немного прогнозирования

Работал с датасетом [Rain in Australia](https://www.kaggle.com/datasets/jsphyg/weather-dataset-rattle-package/data).
Датасет был выбран из-за большого числа численных признаков и таргета, имеющего понятные физические взаимосвязи с признаками. Предсказание дождя на завтрашний день - это интересная практическая задача.  

Для бинарной классификации в качестве таргета был выбран признак RainTomorrow, для регрессии - Temp3pm.  


## Гипотезы
До начала работы были поставлены следующие гипотезы:
1) Удаление пропусков не повлияет на баланс классов.  
2) Парные по времени(9am - 3pm) признаки сильно коррелируют.  
3) На предсказании завтрашнего дождя решающее дерево с гиперпараметрами, подобранными по сетке с помощью кросс-валидации покажет себя лучше логистической регрессии.
4) Использование регуляризации в задаче регрессии признака Temp3pm не даст существенного прироста качества.
5) Наиболее важными признаками для регрессии Temp3pm окажутся признаки имеющие временную составляющую или связанные с температурой и влажностью.


## Выводы
1) Непосредственная проверка подтвердила, что удаление пропусков не повлияло на баланс классов, большое количество пропусков в численных данных было заполнено соответствующим средним значением по соответствующему времени года.
2) Построение таблицы корреляций действительно выявило сильную корреляцию между временными признаками, что позволило избавиться от некоторых из них.
3) Решающее дерево после подбора гиперпараметров действительно показало себя лучше других моделей, вероятно, из-за нелинейного характера зависимости и наличия категориальных признаков сезонности.
4) Изначальная гипотеза в некоторой степени даже оказалась неверна - добавление регуляризации к линейной регрессии ухудшило MSE. Можно предположить, что это произошло из-за нелинейного характера зависимости. К тому же, L1 регрессия вовсе могла удалить признаки имеющие вполне реальное физическое влияние на таргет.
5) Эта гипотеза подтвердилась, что неудивительно. Температура после обеда прямо связана с температурой утром. То же самое можно сказать и про влажность, одну из характеристик воздуха в те же временные промежутки.
